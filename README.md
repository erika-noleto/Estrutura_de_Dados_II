# Estrutura_de_Dados_II

Este repositório foi criado para guardar as atividades/códigos e explicações das aulas de Estruturas de Dados.

## Plano de Estudos

### Unidade I — Revisão das Estruturas de Dados Básicas

**Carga horária: 15 horas**

Conteúdos:

- Tipos de dados primitivos
- Representação do dado na memória
- Arrays unidimensionais
- Matrizes
- Structs
- Dados da memória

---

### Unidade II — Revisão das Estruturas de Dados Complexas

**Carga horária: 15 horas**

Conteúdos:

- Ponteiros de memória
- Filas
- Pilhas
- Listas estáticas
- Listas dinâmicas
- Listas ordenadas
- Listas encadeadas

---

### Unidade III — Grafos

**Carga horária: 15 horas**

Conteúdos:

- Grafos
- Busca em largura
- Busca em profundidade
- Construção de algoritmos utilizando grafos
- Algoritmos de busca em largura
- Algoritmos de busca em profundidade

---

### Unidade IV — Árvores Binárias, Subárvore, Árvores Balanceadas e Heap

**Carga horária: 15 horas**

Conteúdos:

- Árvores binárias
- Subárvores
- Árvores balanceadas
- Heap
- Nós (nodes)
- Arestas (edges)
- Raiz (root)
- Folhas (leaves)
- Altura (height)
- Profundidade (depth)
- Subárvore (subtree)
- Grau de um nó (degree)
- Caminhos
- Níveis
